## 📌 Como resolver e entregar

Faça os exercícios na **sua própria cópia** do repositório do curso. Se ainda não criou a sua, siga o passo a passo de [COMO-OBTER-AS-ATIVIDADES.md](../COMO-OBTER-AS-ATIVIDADES.md).

### 1. Resolva nos próprios arquivos

Abra cada `exercicio_0X_*.py` e complete os trechos marcados com `TODO`, seguindo as instruções do cabeçalho. Para testar:

```bash
python exercicio_01_classes_e_objetos.py
```

### 2. Salve o seu progresso na sua cópia

```bash
git add modulo-05/
git commit -m "feat: exercícios do módulo 5"
git push origin main
```

Para a entrega ao professor, veja a seção **Entregar uma atividade** do guia.
